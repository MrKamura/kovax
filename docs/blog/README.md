# Публикации (blog)

Черновики и тексты для внешних площадок (Habr, DEV.to и т. п.), которые хранятся в репозитории.

| Файл | Язык / формат |
| --- | --- |
| `habr-*.md` | Русский, разметка под Habr |
| `dev-to-*.md` | Английский, YAML frontmatter под DEV.to |
| `habr-theming.md` | Заметки про теминг |

**Локальные наброски без коммита** — каталог **`/blog/`** в **корне** репозитория (см. `.gitignore`): туда можно складывать черновики, они не попадут в git.
