**Публикация на DEV.to:** скопировать тело из `dev-to-*.md` (frontmatter подхватится автоматически при импорте или вставке в редактор).

**Публикация на Habr:** скопировать содержимое `habr-*.md` (Markdown без frontmatter).

**Локальные наброски без коммита** — каталог **`/blog/`** в **корне** репозитория (см. `.gitignore`).
